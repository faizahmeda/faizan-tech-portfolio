Artifact 5: Model Explainability & Decision Matrix

AI/ML • Explainability • Model Evaluation

Introduction

This artifact demonstrates my ability to evaluate, compare, and justify AI/ML model choices based on accuracy, speed, efficiency, and explainability. It reflects my analytical and decision-making skills required in real-world machine learning workflows.

Description

The project analyzes multiple pre-trained models across NLP, Computer Vision, and Tabular ML domains. Each model was evaluated based on size, accuracy, latency, and interpretability. The decision matrix below summarizes these findings and shows which models are best suited for specific scenarios.

Objective

  • Compare ML models across three major AI domains.
  • Understand and explain the trade-offs between model accuracy, speed, and interpretability.
  • Create a decision matrix to guide model selection.
  • Apply explainability concepts such as SHAP and LIME.

Process

  1. Identified widely used pre-trained models.
  2. Researched performance benchmarks from TensorFlow Hub, PyTorch Hub, and Hugging Face.
  3. Compared model size, latency, and accuracy.
  4. Created a structured decision matrix for easy visualization.
  5. Summarized insights and best-fit recommendations.

Tools & Technologies Used

  • Python (Jupyter Notebook)
  • Explainability: SHAP, LIME
  • Model repositories: Hugging Face, TensorFlow Hub, PyTorch Hub
  • XGBoost, Random Forest for tabular ML

Decision Matrix

Model Type Model Name Size Speed Accuracy Explainability Best Use Case
NLP BERT Base Medium Moderate High Medium Text classification & NLP understanding
NLP DistilBERT Small Fast Medium-High Medium Real-time NLP applications
Computer Vision ResNet-50 Medium Moderate High Low High-accuracy image classification
Computer Vision MobileNetV2 Small Very Fast Medium Medium Edge & mobile deployments
Tabular XGBoost Small Very Fast High High Finance, credit scoring, forecasting
Tabular Random Forest Medium Fast High High Healthcare, risk assessments

Value Proposition

This artifact proves my capability to evaluate ML models based not only on accuracy but on deployment feasibility, latency, and explainability. This mirrors how enterprise teams make production-level AI decisions.

Unique Value

The decision matrix provides a clear and concise comparison across domains, enabling engineers and non-technical audiences to understand trade-offs instantly.

Relevance

This artifact aligns strongly with industry expectations for AI/ML engineers, where selecting the right model is as important as building it.

References

  • Deep Residual Learning — He et al.
